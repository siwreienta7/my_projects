# Interpreter (for an assembler-like programming language) 
Интерпретатор assembler-like языка программирования, позволяющий удобно работать с матрицами, поддерживает их загрузку из файлов, доступ к элементам матриц и арифметические операции (сложение/вычитание/умножение).
В ходе работы над проектом создана система обработки исключений разных типов, предотвращающая несколько ошибок ввода команд, ошибки чтения из файлов, аллокации памяти и другие. При этом гарантируется сохранение валидного состояния при получении исключения.
