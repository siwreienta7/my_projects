# Bank server
Проект представляет собой реализацию банковского сервера, поддерживающий операции над пользователями и их счетами в многопоточном режиме.
Реализованы классы, отвечающие за пользователей и их транзакции, гроссбуха. Есть возможность потокобезопасно отслеживать транзакции пользователей в некий момент времени.
Создан TCP-сервер для банка, поддерживающий операции над счетами и авторизацию пользователей.

Как развернуть сервер? Склонируйте репозиторий, перейдите в папку solution. Введите 
```
cmake ./.
make
bank-server <port> <port-file>
```
При помощи этого вы создадите сервер с адресом https://localhost:<port>. Теперь вы можете подключаться к серверу при помощи различных инструментов, например, netcat. Введите:
```
nc localhost <port>
```
